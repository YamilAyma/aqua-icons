## 🚀 Consumo y Uso Creativo

### Activos Multidisciplinarios

Todos los iconos están en formato **PNG de alta resolución con transparencia (alpha channel)**, lo que permite su uso inmediato en diversas herramientas:

- **Diseño Gráfico**: Adobe Photoshop, Illustrator, Canva, Affinity Designer.
- **Prototipado**: Figma, Penpot, Sketch.
- **Video y Motion**: After Effects, Premiere Pro, DaVinci Resolve.
- **Desarrollo**: Astro, React, Next.js, Flutter, Qt.

### Integración

Simplemente arrastra los archivos desde la carpeta `icons/` a tu espacio de trabajo. Si los usas en proyectos de código, se recomienda servirlos como activos estáticos.

## 💡 Escenarios de Aplicación

- **Diseño Editorial y Posters**: Perfectos para composiciones estilo "Frutiger Aero" o arte digital retro-futurista.
- **Interfaces de Usuario (UI)**: Dashboards que requieran un look "tangible" y sofisticado.
- **Identidad Visual**: Como elementos decorativos en presentaciones, branding de productos de IA o recursos de redes sociales.
- **Proyectos de IA**: Los iconos `brain.png` y `robot.png` ofrecen una identidad visual única para asistentes virtuales.

## 🛠️ Contribución y Automatización

Para mantener la calidad y el estilo Aqua clásico (Mac OS X de 2003) en toda la colección, sigue este flujo de trabajo para las contribuciones:

### ⚙️ Requisitos e Instalación

Para poder utilizar los scripts del pipeline de automatización, necesitas tener instalados **Node.js** y **Python (versiones 3.11 a 3.13)**.

Ejecuta el siguiente comando en tu terminal para instalar `rembg` (librería de procesamiento de fondo):

* **Opción estándar (CPU - Recomendada si no tienes GPU NVIDIA dedicada):**
  ```bash
  pip install "rembg[cpu,cli]"
  ```
* **Opción rápida (GPU - Requiere tarjeta NVIDIA y soporte CUDA configurado):**
  ```bash
  pip install "rembg[gpu,cli]"
  ```

### Flujo de Contribución:

1. **Generar el activo:** Utiliza tu generador de imágenes con la plantilla de prompt.
2. **Colocar en raw:** Guarda la imagen generada (sin remover el fondo) en la carpeta `raw-icons/`.
3. **Procesar:** Ejecuta el script de automatización:
   ```bash
   python scripts/process_icons.py
   ```

   Este script se encarga de:* Remover el fondo de las imágenes usando el modelo eficiente `u2net`.
   * Generar commits atómicos independientes por cada icono agregado (`🎨 icon (Aqua) - Add {nombre} icon`).
   * Actualizar la galería de este `README.md` automáticamente.
   * Limpiar la carpeta `raw-icons/` al finalizar con éxito.

### Plantilla de Prompt (Aqua 2003):

> A high-fidelity skeuomorphic icon of `[DESCRIPCIÓN]`, Apple Mac OS X Aqua style from 2003, 3D isometric 3/4 perspective, photorealistic rendering, glossy glass-like texture, vibrant candy-colored highlights, soft liquid reflections, translucent materials, clean white background, studio lighting, soft drop shadow, high resolution, 4k.

### 🧠 Workflow del Asistente (Generación de ideas)

Cuando solicites nuevas ideas de iconos a un asistente de IA, este seguirá los siguientes pasos:

1. **Escanear catálogo:** Ejecutará `python scripts/list_icons.py` para obtener los nombres actuales de los iconos en `icons/` y evitar duplicados.
2. **Idear conceptos:** Propondrá ideas alineadas al estilo retro/de escritorio clásico de 2003.
3. **Formatear descripción:** Entregará únicamente el texto de `[DESCRIPCIÓN]` optimizado para encajar directamente en la plantilla del prompt Aqua.
